PVR Bulk Upload

Upload the ISSF Proactive Vessel Register CSV to update best practice measure statuses. The system compares each vessel's previous values, generates a full change log, records changes in the vessel timeline, and gives you a downloadable audit trail.

Only Project Manhattan admins can upload PVR data.
Step 1 — Select PVR CSV
Match key: UVI Number (IMO/TUVI) — rows are matched to vessels using the UVI Number column. The system loads each vessel's current PVR measures from the database and compares them field-by-field. Only changed values appear in the change log.
