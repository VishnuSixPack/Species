Master orders

Each master order (parent) holds its child shipments. Import an Excel file to create shipments in bulk.

1 · Master = main data, one productShipments are created under it as MO1.1, MO1.2 … and copy its details, so nothing is typed twice. Master Ref no must exist.
2 · Customer order no. is the keyRows with the same master, customer order no. (Purchase Order no.), container and seal are one shipment. Blank container rows continue the row above.
3 · Mixed withShipments of other products with the same customer order no., container and seal are linked automatically. Exact repeats are skipped.
Drop the Excel file to import.xlsx, .xls or .csv using the shipment template
