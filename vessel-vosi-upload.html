VOSI Bulk Upload

Upload the ISSF VOSI CSV export to sync Vessels in Other Sustainability Initiatives. Vessels are matched by UVI Number (IMO). Existing VOSI records for matched vessels are replaced.

Only Project Manhattan admins can upload VOSI data.
Step 1 — Select VOSI CSV file
Match key: UVI Number (IMO/TUVI) — each row in the CSV is matched against your vessel registry using the UVI Number column. The vessel's IMO field must match. Vessels not found in your registry are flagged but not created automatically.
